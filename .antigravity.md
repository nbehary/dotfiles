# Project Instructions

This file contains project-specific instructions for the **Antigravity CLI**. These rules are foundational mandates for the AI agent when operating within this workspace.

## Architecture & Conventions
- **Dotfiles Management:** This project manages system configuration files (dotfiles).
- **Organization:** Configurations are primarily located in `.config/`, with specialized scripts in `scripts/` and custom binaries in `bin/`.
- **Neovim:** Extensive Neovim configuration is located in `.config/nvim/`, using `lazy.nvim` for plugin management.

## Workflows
- **Research First:** Always research existing configurations before proposing changes.
- **Testing:** Verify changes to shell scripts or Neovim configs by dry-running or checking syntax.
- **Commit Style:** Use concise, descriptive commit messages that explain the "why" behind a change.

## CLI Transition
- This project has migrated from Gemini CLI to **Antigravity CLI**.
- Project-specific memory should be stored in `.antigravity.md`.
